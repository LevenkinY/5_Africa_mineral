## 0. 一页纸速览

本工作流围绕两条主线展开:

1. **价值链与进出口描述性分析**: 基于 BACI、UN Comtrade、USGS 已有结果,继续完善非洲关键矿产从本地生产、出口、加工阶梯到下游流向的证据链,重点回答“价值在哪里被加价、被谁捕获、在哪些环节出现统计黑洞”。
2. **影响因素分析**: 在描述性事实之上,进一步解释本地加工能力、治理水平、政府政策和企业特征如何影响矿物出口价格、价值留存和财政收益,重点回答“为什么有些国家/矿种能留住更多价值,有些只能停留在低附加值环节”。

当前已有基础:

| 模块 | 已完成内容 | 下一步用途 |
|---|---|---|
| 钴 / DRC | 加价阶梯、流向、镜像差额、USGS 产量对账 | 作为最强主案例,延伸到 EITI 财政留存与企业控制 |
| 锂 / 津巴布韦 | 加价阶梯、流向、镜像差额、USGS 产量对账 | 作为政策冲击与出口禁令案例 |

| 跨矿种整合 | 三矿种加价倍数、流向集中度、镜像差额对比 | 作为论文核心描述性结果 |

## 1. 总体研究问题与论文逻辑

### 1.1 总问题

非洲关键矿产在全球能源转型价值链中处于什么位置? 价值和利润如何从非洲资源地流向中游加工国、贸易中介和终端工业经济体? 哪些国家能力、政策和企业结构决定了非洲能否获得更高价格和更多本地收益?

### 1.2 可检验命题

| 命题 | 经验含义 | 当前证据状态 | 后续补强方向 |
|---|---|---|---|
| H1 价值落差 | 非洲出口集中在低加工阶段,境外加工品单位价值显著更高 | 已有钴/锂强证据,铜为反例 | 增加稳健性:年份、均值/中位数、含量系数敏感性 |
| H2 流向集中 | 钴、锂高度流向中国等少数加工中心,铜相对分散 | 已有 BACI 流向集中度 | 增加目的地结构变化与 Herfindahl 指数 |
| H3 统计黑洞 | 镜像差额与产量缺口显示漏报、转口、非正规贸易或口径错配 | 已有 Comtrade + USGS 对账 | 形成“黑洞类型学”:低报、零申报、高报、转口再分类 |
| H4 本地加工能力 | 本地冶炼/精炼能力越强,出口单位价值越高,境外溢价越弱 | 铜对照已初步支持 | 构建国家-矿种-年份加工能力指标 |
| H5 治理与政策 | 治理能力、财政制度和产业政策影响价值留存 | 尚未系统展开 | 接入 EITI、WGI/IIAG、政策事件库 |
| H6 企业控制 | 外资来源、垂直整合和长期采购关系影响定价与利润留存 | 尚未系统展开 | 建立重点矿山/企业所有权表 |

### 1.3 论文主线

```text
资源禀赋
  -> 生产与出口结构
  -> HS 加工阶梯中的单位价值差异
  -> 双边流向与中游捕获者
  -> 镜像差额/产量缺口暴露的数据黑洞
  -> 本地加工、治理、政策、企业结构解释差异
  -> 非洲关键矿产价值留存与产业政策建议
```

## 2. 主线一: 价值链与进出口描述性分析

### 2.1 核心问题

1. 非洲重点国家在钴、锂、铜价值链中分别处于哪个加工阶段?
2. 从矿石/精矿到氧化物、碳酸盐、粗金属、精炼金属,单位价值如何变化?
3. 中国、瑞士、欧盟、美国及其他亚洲经济体在不同矿种中分别扮演什么角色?
4. 出口国申报与伙伴国进口申报之间的差额是否具有系统性?
5. USGS 产量与报关出口折金属量之间的差距反映了什么样的统计与治理问题?

#### Task 1.4 镜像差额类型学

基于已完成的 Comtrade 审计,将每个矿种-HS6-年份划分为:

| 类型 | 判定 | 可能含义 |
|---|---|---|
| 伙伴进口显著高于出口国申报 | partner import > exporter export | 出口低报、转口、离岸定价、统计漏记 |
| 出口国申报显著高于伙伴进口 | exporter export > partner import | CIF/FOB 口径外的再出口、伙伴缺报、World 行重复/口径问题 |
| 出口国零申报但伙伴有进口 | exporter export = 0, partner import > 0 | 高价值品漏报或 HS 再分类 |
| 双方均低但 USGS 产量高 | trade low, production high | 库存、境内加工、走私或非正规渠道 |

输出:

- `outputs/tables/mirror_gap_typology.csv`
- 论文小节: “数据黑洞不是缺陷,而是价值转移机制的一部分”

## 3. 主线二: 影响因素分析

### 3.1 核心问题

1. 本地加工能力是否提高非洲矿物出口单位价值?
2. 本地冶炼/精炼能力是否降低境外加工国的加价倍数?
3. 治理质量是否影响镜像差额、价值留存和财政收益?
4. 出口禁令、本地加工要求、矿业税制改革等政策是否促进本地增值,还是造成贸易收缩和统计黑洞扩大?
5. 企业所有权、外资来源和垂直整合是否影响非洲在价值链中的议价能力?

### 3.2 变量体系

#### 结果变量

| 变量 | 构造 | 层级 |
|---|---|---|
| 出口单位价值 | export value / quantity | 国家-矿种-HS6-年份 |
| 加工品出口占比 | processed HS value / total mineral value | 国家-矿种-年份 |
| 境外加价倍数 | downstream country UV / African exporter UV | 矿种-HS6-年份 |
| 镜像差额率 | (partner imports - exporter exports) / exporter exports | 国家-矿种-HS6-年份 |
| 物理缺口率 | (USGS production - trade metal content) / production | 国家-矿种-年份 |
| 财政留存率 | government mining revenue / mineral export value | 国家-年份或项目-年份 |

#### 核心解释变量

| 模块 | 变量 | 来源 |
|---|---|---|
| 本地加工能力 | 是否有冶炼/精炼产能、加工品出口占比、加工产能规模 | AGMO、USGS、公司年报、项目资料 |
| 治理水平 | 腐败控制、法治、政府效能、监管质量 | WGI、IIAG、NRGI RGI |
| 政府政策 | 出口禁令、本地加工要求、特许权使用费、税率改革、国家持股 | 政策文本、OECD/IGF、新闻与政府公告 |
| 企业特征 | 所有权、母公司国别、是否中资/欧美/本地、是否垂直整合 | 公司年报、S&P/公开资料、项目清单 |
| 市场结构 | 目的地 HHI、Top1 份额、中国份额 | BACI |
| 控制变量 | 国际价格、产量、储量、基础设施、GDP、人均电力、港口距离 | World Bank、USGS、WDI、地理数据 |

### 3.4 计量与识别方案

#### Model A: 本地加工能力与出口单位价值

```text
log(UV_cmy) = alpha
            + beta ProcessingCapacity_cmy
            + gamma Governance_cy
            + delta MarketConcentration_cmy
            + theta Controls_cmy
            + country_mineral FE
            + year FE
            + error_cmy
```

解释:

- `c`: 国家; `m`: 矿种; `y`: 年份。
- 重点系数 `beta`: 本地加工能力是否提高出口单位价值。
- 可先用小样本描述性回归,不急于过度声称因果。

#### Model B: 政策冲击的事件研究

适用政策:

- 津巴布韦锂出口禁令/本地加工要求。
- DRC 钴出口限制/配额。
- 赞比亚铜税制或冶炼政策调整。

```text
Y_cmy = alpha
      + sum_k beta_k EventTime_k
      + country_mineral FE
      + year FE
      + controls
      + error_cmy
```

结果变量:

- 原矿出口量。
- 加工品出口占比。
- 单位价值。
- 镜像差额率。
- 物理缺口率。

注意:

- 样本国家少时,事件研究更适合作为“结构化案例分析 + 图形证据”,不宜包装成强因果。
- 需要明确政策执行时间与过渡期。

#### Model C: 财政留存与治理能力

```text
FiscalRetention_cy = alpha
                   + beta Governance_cy
                   + gamma ProcessingShare_cy
                   + delta ExportValue_cy
                   + country FE
                   + year FE
                   + error_cy
```

用途:

- 检验出口价值增长是否真正转化为政府收入。
- 连接“价值链加价”与“本地利润/财政收益”。

#### Model D: 企业所有权与价值捕获

在企业/项目数据可用时使用:

```text
Outcome_pmy = alpha
            + beta ForeignOwnership_p
            + gamma ChineseOwnership_p
            + delta VerticalIntegration_p
            + theta ProcessingFacility_p
            + mineral FE
            + year FE
            + error_pmy
```

结果变量:

- 项目级付款。
- 估算出口价值。
- 是否进入加工环节。
- 是否出现长期包销或单一目的地依赖。

## 6. 章节写作提纲

### 第一章 引言

- 全球能源转型推高关键矿产需求。
- 非洲拥有关键资源,但多数国家仍停留在低附加值环节。
- 研究问题: 价值在哪里被捕获? 本地收益为何有限? 哪些因素改变这一结构?
- 贡献:
  - 用 HS 加工阶梯量化价值落差。
  - 用 BACI + Comtrade + USGS 交叉识别价值流向与统计黑洞。
  - 将描述性价值链证据推进到加工能力、治理、政策和企业结构解释。

### 第二章 数据与变量

- 矿种与国家选择。
- HS 加工阶梯。
- BACI、UN Comtrade、USGS、EITI、治理和企业数据。
- 单位价值、加价倍数、流向集中度、镜像差额、物理缺口、财政留存率的构造。
- 两条边界:
  - 单位价值是“价值/增值分配”,不是严格利润。
  - 镜像差额和产量缺口是“黑洞规模”,不是逐笔走私证明。

### 第三章 描述性事实: 价值链位置与加价阶梯

- 钴、锂强烈境外加价。
- 铜因 LME 定价和本地冶炼出现对照。
- 三矿种并列表呈现差异。

### 第四章 流向、镜像差额与统计黑洞

- 目的地集中度。
- 中国作为钴、锂中游枢纽,瑞士/中国在铜中的不同角色。
- 镜像差额类型学。
- 产量-贸易物理对账。

### 第五章 影响因素: 加工能力、治理、政策与企业结构

- 本地加工能力与出口单位价值。
- 治理水平与财政留存。
- 出口限制/加工要求政策事件。
- 企业所有权与垂直整合。

### 第六章 案例讨论

- DRC 钴。
- 津巴布韦锂。
- 赞比亚铜。
- DRC 铜。

### 第七章 结论与政策建议

- 非洲关键矿产的价值链困境不是资源缺乏,而是加工能力、定价权、治理能力和企业控制结构共同作用。
- 政策建议:
  - 提升本地加工能力,但避免简单出口禁令造成贸易收缩。
  - 加强价格审计、受益所有人披露和转移定价监管。
  - 通过区域合作建设共享冶炼、能源和物流基础设施。
  - 将矿业收入转化为财政、就业、能源接入和产业升级。

## 8. 风险与处理原则

| 风险 | 影响 | 处理 |
|---|---|---|
| HS 编码不完全对应矿物 | 锂 `253090`、铜精矿品位可能偏差 | 用含量系数敏感性和文字说明处理 |
| 单位价值不等于利润 | 不能直接声称企业利润率 | 使用“价值捕获/增值分配”,利润部分需 EITI/公司数据补充 |
| 镜像差额解释不唯一 | 可能来自 CIF/FOB、再出口、统计口径 | 做类型学,避免单一归因为走私 |
| 国家样本较小 | 计量识别强度有限 | 采用“描述性面板 + 事件图 + 案例机制”的组合 |
| 政策时间点复杂 | DID 可能不稳 | 先做事件研究图和制度叙事,谨慎声称因果 |
| 企业数据不完整 | 项目级分析缺口 | 先覆盖重点矿山和上市公司,用公开资料注明可信度 |
