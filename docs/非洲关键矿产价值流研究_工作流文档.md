## 0. 一页纸速览(TL;DR)

- **研究问题(主线)**:在全球绿色转型名义下,撒哈拉以南非洲关键矿产价值链上,**价值与利润究竟流向了何方?**
- **三种矿种**:钴(刚果金)、锂(津巴布韦)、铜(赞比亚 + 刚果金铜带)。
- **最小数据库栈**:**BACI + UN Comtrade + USGS**(全部免费);若做财政留存再加 **EITI**。
- **核心方法**:沿 HS 编码加工阶梯取单位价值 → 量化各环节加价(价值落差)+ 双边流向 + 镜像差额(漏报)+ 产量缺口(走私/非正规)。
- **两条边界**:得到的是**增值/加价分配**而非严格利润;缺口是**框定黑洞规模**而非逐笔还原。

## 1. 研究主线

### 1.1 核心命题

全球绿色转型存在一个悖论:全球北方为实现自身的低碳与"公正",通过关键矿产价值链,把"不绿色"与"不公正"结构性地转嫁并锁定在撒哈拉以南非洲。研究要做的,是把这种"隐性殖民"从道德直觉变成**可追踪、可量化的实证证据**。

贯穿始终的追踪线:**价值与利润流向何方**。所有材料都挂在这一个问题上。

### 1.2 四层论证逻辑(递进,而非并列)

| 层次 | 任务 | 内容要点 |
|---|---|---|
| **现象层** | 证存在 | 三重不对称:① 价值捕获不对称(原料低价出境、装备溢价反销);② 发展红利被系统性剥夺(出口绿色资源却近半人口无电);③ 生态与社会成本地方化("全球受益、本地买单") |
| **机制层** | 释为何持续 | 双重成因交织:对外=全球北方结构性垄断(技术/人才/资金真空→定价权与规则权旁落,甚至"离岸平衡"式默许冲突);对内=非洲治理溃败与精英捕获(立法缺失、政策不稳、腐败) |
| **方法层** | 障碍即机制 | 三重数据黑洞:跨国公司信息黑箱、非正规经济隐形化、供应链中间商迷雾。**这些黑洞本身就是掩盖不平等的机制**——把"测不准"做成发现,是论文亮点 |
| **实证落脚点** | 从批判转向追踪 | 重构"矿石开采→中间商→离岸定价→精深加工→溢价反销"的价值流向图谱,量化各环节利润分配 |

### 1.3 价值链与论证主线(示意)

```
            核心命题:绿色转型的"不公正"悖论
   ┌────────── 追踪主线:价值与利润流向何方? ──────────┐
   ▼                                                    ▼
价值链: 非洲矿石开采 → 中间商交易 → 离岸低价 → 全球北方/中国精深加工 → 溢价反销非洲
            │            │           │              │
利润漏出 → 本土精英    中间商网络   定价权丧失    加工/工业化经济体(主要捕获者)
            ↓
成本沉淀 → 环境破坏、资源掠夺、发展停滞,全部由非洲底层社区承担

现象层(证存在) → 机制层(释为何持续) → 方法层(障碍即机制) → 实证落脚点(微观追踪)
```

## 2. 数据库选型

按价值流追踪逻辑,数据库分为三个功能层。单一数据库无法覆盖全链条,需要**组合**。

### 2.1 三个功能层与候选库

| 数据库 | 数据类型 | 分辨率 | 时间跨度 | 获取/API | 费用 |
|---|---|---|---|---|---|
| **UN Comtrade (Plus)** | 双边进出口额、数量、CIF/FOB、单位价值、镜像 | HS 2/4/6 位,200+ 国,年+月 | 1962– | API(需 key,免费档单次 500 条上限,订阅 25 万),Python/R 库 | 免费(预览);批量下载需订阅 |
| **BACI (CEPII)** | 重构后双边贸易额+数量(统一 FOB),可算单位价值 | HS6,约 226 国,年度 | 1995–2023 | CSV 批量下载(需 Comtrade 账号登录) | 免费(Etalab) |
| **WITS** | Comtrade 贸易 + TRAINS/WTO 关税与 NTM + 加工阶段分类 | HS6(+SITC/BEC/阶段),年度 | 1962– | 网页 + API(SDMX/URL),R/Python | 免费(注册) |
| **OEC** | 贸易流 + 复杂度指数 + 可视化 | HS6,年度;部分月度/次国家级 | HS 1995–2024 | 网页可视化 + REST API(部分免费,最新/批量需 Pro) | 免费档;Pro $299/月(学术 5 折) |
| **USGS (MCS/MIS)** | 各国矿山产量、储量、价格、进出口依赖 | 国别(非双边),按矿种 | 长序列(百年级) | PDF + ScienceBase 机读数据集 | 免费(公共领域) |
| **EITI** | 产量/出口、公司对政府付款、收入流,项目级 | 国别/公司/项目,50+ 国 | 各国不一 | 国家页面 + Summary Data Template | 免费 |
| **NRGI ResourceData** | 公司付款(项目级)、合同、治理指数 | 项目/公司级 | — | 网页下载 | 免费 |

### 2.2 各库定位与取舍

**第一层 跨境贸易流(价值链骨架)**

- **UN Comtrade(Comtrade Plus)**:全球双边贸易权威底库,进口记 CIF、出口记 FOB,可算单位价值,**保留进出口双方原始申报**(漏报/转移定价的核心信号)。局限:缺失与噪声多、清洗成本高、批量需订阅。官方库 `comtradeapicall`(Python)/`comtradr`(R)。
- **BACI(CEPII)**:基于 Comtrade,用引力模型把 CIF 折回 FOB、按申报可靠性加权**调和**出单一值与数量,可直接算干净的单位价值。**关键局限:把镜像差额"消掉"了**——适合做加价分析,不适合做漏报检测(那必须回原始 Comtrade)。
- **WITS / OEC**:辅助。WITS 提供关税/NTM 与"加工阶段"分类,补政策线;OEC 适合快速可视化探索(当踩点工具,正式数据以 Comtrade/BACI 为准)。

**第二层 上游实物与价格(贸易数据看不见的矿口)**

- **USGS(MCS / MIS / DS140)**:各国矿山产量(含部分手工采矿估算)、储量、价格;公共领域、可机读下载。补上贸易数据盲区,把"离岸 FOB"锚定到"矿口实物"。局限:国别非双边,不含中间商。
- 价格基准:World Bank "Pink Sheet"(免费)含铜/镍/铝等,但**不含钴、锂**;电池金属细分价需 LME 或商业源(Benchmark、Fastmarkets、S&P,付费)。

**第三层 财政与利润留存(钱留下多少)**

- **EITI + NRGI ResourceData**:按价值链披露公司对政府付款、收入流,项目级。唯一能直接量化"价值捕获不对称"和"精英捕获"的源。局限:各国报告口径不一,可比性受限。

### 2.3 优先级结论

1. **第一优先(主干):UN Comtrade 原始数据 + BACI**。Comtrade 保留双方申报→镜像差额/漏报;BACI 提供清洗后单位价值→加价量化。两者免费、均可下钻 HS6。
2. **第二优先(两翼):USGS + EITI/NRGI**。USGS 封"最上游"(矿口产量+走私缺口),EITI 封"最末端"(财政留存),正好对应三大黑洞中的两个。
3. **辅助**:WITS(关税/加工阶段)+ OEC(快速探索)。**进阶**:OECD TiVA / Eora MRIO(增加值视角,但矿业为单一粗行业,仅宜宏观佐证)。

## 3. 矿种确定

### 3.1 选择标准

绿色转型核心地位 × SSA 产量主导性 × 价值落差的鲜明程度 × 可追踪性(衔接数据库)。背景:SSA 握有近 30% 全球关键矿产储量;IEA 预计 2022–2050 钴需求增至三倍、锂增至十倍。

### 3.2 三种矿种

| 矿种 | 核心产区与地位 | 价值落差/政策抓手 | 数据可追踪性 |
|---|---|---|---|
| **钴** | 刚果金占全球钴产量逾 70%、约半数已探明储量 | 出口钴氢氧化物中间品、由中国精炼;2025 出口禁令→弹性配额;DRC 正建本地精炼;手工采矿庞大 | HS 2605/2822/8105;DRC 为 EITI 实施国 |
| **锂** | 津巴布韦握非洲最大锂储量,2025 出口 112.8 万吨锂辉石精矿,约占中国锂精矿进口 15% | 精矿多运往中国加工;约 80% 产能中资控股;2022/2026 出口禁令;政府估走私致约 18 亿美元收入流失 | HS 2530.90/2825.20/2836.91;镜像差额+走私转口=黑洞实证 |
| **铜** | DRC+赞比亚推动非洲 2025 铜年产约 420 万吨;赞比亚全球第七 | 中部非洲铜带=殖民式攫取经典地带;**部分本地冶炼**但深加工与定价在外 | HS 2603/7402/7403;赞比亚 EITI 数据扎实,可做赞比亚—刚果金对比 |

**被排除的近似项**:铂族金属(南非本土已有较完整精炼,落差被削弱)、锰、石墨(政策戏剧性与数据可得性偏弱)。**最强备选/第四种**:铝土矿(几内亚,全球最大出口国、几乎零本地加工,"零增值"最纯粹范例,且补西非视角)。

### 3.3 必须正视的分析张力(潜在贡献点)

访谈把矛头指向"全球北方",但追踪钴、锂的价值流时,数据会反复指向**中国**才是中游精炼与定价的主要捕获者。可把"全球北方 vs 全球南方"的二元叙事,修正为:**加工/工业化经济体(以中国为枢纽)捕获中游价值、西方捕获终端消费红利、非洲滞留底端**的三层结构。提前想清楚这一点,论文更稳。

## 4. HS 编码加工阶梯(取数坐标系)

核心逻辑:沿阶梯逐级取**单位价值(value/quantity)**,相邻两级之差即该环节加价;非洲出口集中在最底一两级,价值在境外向上爬升=不对称的可量化证据。

> 通用提醒:6 位码全球统一,但须在**同一 HS 修订版**内取数(BACI 按修订版分文件);8 位以上是各国扩展,跨国不可比。

### 4.1 钴(刚果金)

| 阶段 | HS6 | 品名 | 研究含义 |
|---|---|---|---|
| 矿石/精矿(未精炼) | **2605.00** | 钴矿石及精矿 | DRC 实际多为铜钴 heterogenite 精矿;链条最底端、离岸 FOB 起点 |
| 中间化合物 | **2822.00** | 钴的氧化物与氢氧化物 | DRC 主力中间品=钴氢氧化物,第一道增值 |
| 精炼金属 | **8105.20** | 钴锍及冶金中间品、未锻轧钴、粉末 | "精炼钴",主要在中国 |
| 电池前驱体 | (无专用 HS6,并入 2833 硫酸盐) | 硫酸钴 | 电池正极关键前驱体,贸易数据难单独剥离——缺口本身即发现 |

## 5. 最小数据集

把研究目的拆成**四个必证命题**,每个对应一份最小数据,看清"少到不能再少"的边界。

| 必证命题 | 最低数据 | 数据库 | 产出 |
|---|---|---|---|
| ① 价值落差(各环节加价) | 阶梯上每个 HS 码的"金额+数量"→单位价值 | **BACI** | 加价阶梯图:矿口→中间品→精炼的价格倍数 |
| ② 流向(谁捕获) | 同一批数据的双边伙伴维度 | **BACI**(双边) | 价值流向图:非洲→中国→世界 |
| ③ 价值漏出/低报 | 出口国申报 vs. 伙伴国申报(原始镜像) | **UN Comtrade 原始数据** | 镜像差额=漏报/转移定价信号 |
| ④ 走私/非正规缺口 | 各国矿山产量(实物) | **USGS** | 产量 vs. 报关出口的实物缺口 |

**最小数据库栈 = BACI + Comtrade + USGS(三个,全部免费)**;若量化"政府收入留存率",再加第四个 **EITI**(DRC、赞比亚数据扎实;津巴布韦较弱)。

### 5.1 把范围压到最小的四个参数

- **矿种**:先做**一种矿打通全链**(建议钴/DRC),验证方法后复制到锂、铜。证明方法的最低成本是 1 种矿端到端。
- **地理**:只取**核心出口国 + 前 3–5 个伙伴 + "World"汇总**,不必拉全 200 国。
- **时间**:**2010–2023 年度**(BACI 区间),足够显示趋势。
- **产品**:阶梯里的 **3–4 个 HS 码**。

### 5.2 必须诚实划清的两条边界

1. **单位价值给的是"价格加价(markup)分配",不是严格"利润分配"**。利润=加价−成本,而成本数据(矿山现金成本、加工成本)在免费库里没有,需公司年报或 S&P/Benchmark 成本曲线(付费)。最低数据稳稳支撑的核心论点是"**价值/增值在各环节的分配不对称**",已足以证成命题;真要谈利润率,要么补成本假设、要么标注为局限。**建议论文用"价值捕获/增值分配"措辞**。
2. **中间商转口与走私无法被免费数据完全解析**(钴经赞比亚/南非转口、锂走私到南非/阿联酋)。最低数据能做的是**用镜像差额+产量缺口把"黑洞"框定并量化其规模**,而非逐笔还原。这恰好契合访谈立场——把"测不准"做成发现。

## 6. 可执行操作卡(钴 / DRC)

### 6.0 一次性准备

- 在 comtradeplus.un.org 注册拿免费 API key(账号满 15 天后可填表申请 15 天试用以批量下载)。
- 用同一账号登录 CEPII 下载 BACI(选一个 HS 修订版即可,钴的三码各版本稳定)。
- `pip install comtradeapicall pandas`。

### 6.1 代码参照表

**国家(Comtrade/BACI 通用数字码)**:DRC=`180`、中国=`156`、赞比亚=`894`、南非=`710`、芬兰=`246`、比利时=`56`、World=`0`(仅 Comtrade 有"世界"汇总;BACI 只有双边,需自行对伙伴求和)。

**产品 HS6**:`260500` 钴矿石及精矿 / `282200` 钴氧化物与氢氧化物 / `810520` 未锻轧钴及冶金中间品。

### 6.2 BACI:加价阶梯 + 流向(命题 ①②)

BACI 为逐年 CSV,列为 t(年)、i(出口国)、j(进口国)、k(HS6 产品)、v(值,千美元,调和后 FOB)、q(数量,吨)。单位价值 `uv = v/q`(千美元/吨 ≈ 美元/千克)。

```python
import pandas as pd, glob
frames = [pd.read_csv(f, dtype={'k': str})           # k 当字符串,防丢前导零
          for f in glob.glob('BACI_HS17_Y20*.csv')]
baci = pd.concat(frames)

co = baci[(baci.i == 180) & (baci.k.isin(['260500','282200','810520']))].copy()
co['uv'] = co.v / co.q                                # 单位价值

# 加价阶梯:DRC 各级出口的加权单位价值
ladder = co.groupby(['t','k']).apply(
    lambda d: d.v.sum()/d.q.sum()).unstack('k')        # 看 260500→282200→810520 倍数

# 流向:DRC 矿石精矿出口的买家份额
flow = (co[co.k=='260500'].groupby('j').v.sum()
        .sort_values(ascending=False))
```

`ladder` 三列单位价值之比="矿口→中间品→精炼"加价倍数(命题①);`flow` 份额=价值去向(命题②)。可再取中国(i=156)对世界再出口 810520 的单位价值,与 DRC 出口端对照,量化境外捕获差额。

### 6.3 Comtrade:镜像差额(命题 ③)

```python
import comtradeapicall as ct
```

**关键现实提醒**:DRC 对 Comtrade 申报极不完整、常年缺失——A 面很可能取不到数据,这本身即"信息黑箱"的直接印证。届时改用两条退路:
1. 用多个伙伴国(中国+赞比亚+芬兰…)报告的"自 DRC 进口"之和,与 USGS 产量对照;
2. 直接以伙伴镜像数据作为 DRC 出口的代理。

### 6.4 USGS:产量锚 + 物理对账(命题 ④)

取 MCS 钴章 / ScienceBase 数据集里 DRC 的**年度钴矿产量(钴金属含量计,吨)**。难点是**单位口径不一致**:贸易量 260500 是精矿毛重(钴品位低)、282200 是化合物重、810520 近纯钴;产量是钴含量。须把各级贸易量统一换算成"钴含量吨"再比。

参考转换系数(纯化合物):Co(OH)₂ ≈ 63% Co、Co₃O₄ ≈ 73% Co、未锻轧钴 ≈ 99% Co;**但 DRC 出口的粗制氢氧化物商品品位更低(约 30–40%)**,务必按实际 assay/产品规格取系数,勿套纯品值。换算后"产量 − 报关出口(钴含量)"的缺口即走私/非正规采矿量级。

### 6.5 产出与边界

跑完得到三张核心结果:**加价阶梯图、价值流向图(DRC→中国→世界)、缺口估计(镜像差额 + 产量缺口)**。

**复制到锂、铜**:国家换成 `716`(津巴布韦)/`894`(赞比亚),HS 码换成各自阶梯,流程完全复用。注意锂的 `253090` 是"其他矿物质"大类,需先用单位价值和产区把锂辉石从杂项里甄别出来。

继续守住两条边界:得到的是**增值/加价分配**而非利润;缺口是**框定黑洞规模**而非逐笔还原。在方法部分明确写出,反而是研究严谨性的体现。
