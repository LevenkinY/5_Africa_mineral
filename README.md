# Africa Critical Minerals and Unequal Green Transition

本项目用于协作推进一项关于非洲关键矿产、全球绿色转型与不公正发展的研究。当前研究从访谈材料出发，关注全球绿色转型如何通过关键矿产价值链，把生态、社会和发展成本留在非洲本地，同时将高附加值加工、利润和技术能力转移到全球价值链上游或下游的强势主体。

## 研究问题

当前核心问题可以表述为：

> 在全球绿色转型对关键矿产需求快速上升的背景下，非洲资源国是否只是承担了矿产开采的社会生态成本，而没有获得相应的价值增值、财政收益和本土发展红利？

可进一步拆分为四组可实证化问题：

1. 非洲在钴、铜、锂、锰、镍、铂族金属、石墨、稀土等关键矿产供应中处于什么位置？
2. 关键矿产从非洲流向哪里，在哪些环节发生价值增值和利润转移？
3. 矿业收入、企业付款和合同安排是否转化为政府财政、公共服务、能源可及性或地方发展？
4. 矿区社区承担了哪些环境、人权、健康、冲突和非正规劳动成本？

## 协作方式

建议使用 GitHub Issues 管理任务，使用 Pull Requests 合并修改。每个任务尽量对应一个明确产出，例如：

- 新增或核验一个数据库来源
- 整理一个国家或矿种案例
- 补充一组文献摘要
- 建立一个数据字典
- 清洗一张原始数据表
- 撰写或修改一节论文草稿

协作者提交内容前，请先阅读 [CONTRIBUTING.md](CONTRIBUTING.md) 和 [docs/数据管理说明.md](docs/数据管理说明.md)。

## 推荐目录结构

当前项目仍处于研究设计阶段。后续建议按以下结构扩展：

```text
data/
  raw/          # 原始数据，不手工修改
  interim/      # 中间清洗结果
  processed/    # 可复现实证分析使用的数据
  external/     # 外部下载说明或轻量引用文件
docs/           # proposal、访谈、文献、会议材料、数据源说明
literature/     # 文献笔记、引用库导出、阅读摘要
notebooks/      # 探索性分析
scripts/        # 数据下载、清洗、合并、制图脚本
outputs/
  tables/       # 回归表、描述统计表
  figures/      # 图表
paper/          # 论文草稿
```

大型原始数据、商业数据库下载件、含权限限制的数据、个人访谈录音或敏感材料不应直接提交到公开仓库。

## 项目材料目录

迁移后的项目材料以 `docs/materials_index.md` 为总索引。研究设计材料放在 `docs/proposals/`；文献综述和源文献放在 `literature/`；价格、贸易和项目级资产参考材料放在 `data/external/`。

## 敏感材料处理规则

访谈原件、商业数据库导出、账号授权下载件和任何含个人身份信息的材料仅保存在 `_private/`。该目录由 `.gitignore` 排除；仓库只记录元数据、来源说明、用途和引用限制。

## 研究状态

项目当前处于选题收敛与数据可得性验证阶段。下一步重点是：

1. 确定核心分析对象：国家、矿种、矿山项目或矿区社区。
2. 验证关键数据库是否可下载、可复现、可合并。
3. 建立最小可行数据表，先证明研究问题可以被经验材料支撑。
4. 将访谈中的规范性判断转化为可检验的指标和假设。

## 许可与引用

当前仓库包含研究草稿、访谈整理和数据源笔记。正式开源许可、数据再分发规则和引用格式需要在确认数据权限后再最终确定。
