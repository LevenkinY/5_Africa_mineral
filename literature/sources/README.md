# Literature Sources

This folder stores source documents used for the literature review.

- `journal_articles/`: peer-reviewed articles and journal-style working papers.
- `institutional_reports/`: policy reports, development institution reports, and official strategy documents.
- `jimf_methods/`: commodity price and international finance methods literature relevant to the JIMF framing.
- `hubin_background/`: background materials migrated from the HuBin folder.

Check redistribution rights before making this repository public.
