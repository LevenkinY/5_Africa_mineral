# Literature Review Outputs

This folder stores reusable literature review workbooks, extracted context files, and notes describing how the review artifacts were generated.

Generated scratch scripts live under `scripts/literature_review/` when they are useful for reproducing the review.

## Files

- `literature_review_source.xlsx`: workbook migrated from the original `literatures/` folder.
- `literature_review_generated.xlsx`: generated review workbook from the prior `outputs/` folder.
- `literature_context.json`: extracted context used by the literature review workflow.
